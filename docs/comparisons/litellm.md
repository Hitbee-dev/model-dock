# ModelDock vs LiteLLM

LiteLLM is the LLM gateway and proxy layer. ModelDock is the end-user and operator layer on top of LiteLLM.

## What LiteLLM handles

- Provider routing.
- OpenAI-compatible API surface.
- Virtual keys.
- User and team budgets.
- Spend tracking.

## What ModelDock adds

- Signup and auth.
- BYOK provider settings.
- Credential vault.
- Credits UI and ledger.
- Chat UI.
- Admin workflows.
- Deployment baseline and public docs.
