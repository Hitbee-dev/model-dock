# FAQ

## What is ModelDock?

ModelDock is an open-source control plane for self-hosted multi-user LLM apps built on LiteLLM.

## Is ModelDock a model provider?

No. ModelDock routes to configured provider APIs and OpenAI-compatible endpoints through LiteLLM.

## Can I share one personal AI subscription with many users?

Do not use ModelDock to share a single personal AI subscription account across multiple users unless the provider's terms explicitly allow it.

## Does ModelDock require provider keys to start?

No. The scaffold starts without provider keys. Real model calls require user-owned or platform-owned provider credentials.
