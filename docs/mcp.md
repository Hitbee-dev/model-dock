# MCP

ModelDock will make MCP server configuration easy and safe.

## What is MCP in ModelDock?

MCP support lets users configure tools with explicit permission prompts, per-user settings, and audit metadata without leaking secrets.

## Planned features

- MCP server registry UI.
- Per-user MCP configuration.
- Workspace-level configuration later.
- Permission prompt before tool execution.
- Secret fields that are write-only.
- Tool call audit metadata without sensitive payloads.

## Security caveats

Risky tools must be disabled by default and explicitly enabled.
